# Enterprise Network & Cybersecurity Lab

## Overview

This project documents the design, implementation, security, and testing of a simulated enterprise network using Cisco Packet Tracer. The project is being developed in phases, with each phase introducing new networking, systems administration, and cybersecurity concepts.

The final aim is to build a realistic, fully documented enterprise environment that can later be used as a controlled cybersecurity lab for security testing, vulnerability assessment, and hardening.

---

## Objectives

- Design a scalable enterprise network.
- Implement VLAN segmentation and inter-VLAN routing.
- Deploy centralized network services.
- Practice network troubleshooting and documentation.
- Secure network devices using SSH.
- Secure switch access ports using port security and sticky MAC addresses.
- Control inter-VLAN traffic using ACLs.
- Build a foundation for later cybersecurity testing using Kali Linux and VMware.
- Document configuration, testing, problems, and solutions.
